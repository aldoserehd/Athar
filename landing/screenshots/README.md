## Recommended size

- ~1080 × 2340 px (typical Android portrait), or
- 1290 × 2796 px (iPhone 6.7" portrait)

Any portrait PNG works — the frames use a ~9 / 19.5 aspect ratio and will
scale the image to fit. Aim for consistent dimensions across all six so the
grid/carousel looks even.

## Notes

- Keep the filenames lowercase and numbered `1.png` … `6.png`.
- If a file is missing, its frame degrades gracefully to a dark on-brand
  placeholder background (no broken-image layout shift).
- Optimize/compress the PNGs before committing to keep the page light.
